군포시청 감사실이 보유한 감사사례 데이터를 공무원이 쉽게 검색·열람할 수 있도록 만든 정적 웹 애플리케이션입니다.

## 기술 스택

- **Frontend:** HTML5 · CSS3 · Vanilla JavaScript (의존성 없음)
- **데이터:** Excel → Python(`excel_to_data.py`) → `.js` / `.json` 이중 포맷
- **배포:** GitHub Pages (`/docs` 폴더, 자동 배포)
- **자동화:** `업데이트.sh` — 엑셀 변환 + git commit + push 원스텝

## 데이터 업데이트 방법

엑셀에 행을 추가하고 스크립트 하나만 실행하면 웹에 반영됩니다.

```bash
# 1. 검토상태표_v2.1.xlsx 편집 (행 추가 또는 수정)
# 2. 아래 명령 실행
./업데이트.sh
```

스크립트가 자동으로: ① 엑셀 → JS/JSON 변환 → ② git commit → ③ push → ④ GitHub Pages 배포

> **반영 주기:** push 후 약 1~2분 내 라이브 URL에 적용됩니다.

### 엑셀 필수 컬럼

| 열 이름 | 설명 |
|---|---|
| 사례번호 | 고유 ID (예: `bai-01`) |
| 감사기관 | 감사원 / 서울특별시 감사위원회 / 서대문구 등 |
| 감사명 | 감사 건명 |
| 게시일 | YYYY-MM-DD |
| 분야 | 계약·회계 / 복무 / 인사·채용 등 |
| 지적제목 | 사례 제목 |
| 요약 | 지적 내용 요약 |
| 처분 | 시정 / 주의 / 통보 등 (복수는 `·` 구분) |
| 검토상태 | `approved` 또는 `source_checked` 인 행만 웹에 공개됨 |
| 공식 게시물 | 원문 URL |

## 운영 안내

### 다른 사람이 웹을 열람하는 방법
배포 주소 `https://sunnyhan5651.github.io/Web_Searching_System` 를 공유하면 됩니다. 로그인 없이 누구나 접근 가능합니다.

### 파일로 직접 실행하는 방법 (인터넷 없는 환경)
1. 이 저장소를 ZIP으로 다운로드 → **"모두 압축 풀기"** 실행
2. `docs/index.html` 파일을 더블클릭

> ZIP 파일 안에서 바로 열면 동작하지 않습니다. 반드시 압축 해제 후 실행하세요.
