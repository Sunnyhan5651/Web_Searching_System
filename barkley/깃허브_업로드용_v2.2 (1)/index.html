이렇게 찾아보세요

  1. 담당 업무 용어를 입력합니다. 예: 계약, 보조금, 출장, 채용, 공유재산.
  2. 입력한 단어가 그대로 들어간 사례가 먼저 나오고, 관련 표현(예: 계약 → 수의계약, 변경계약, 이행보증)으로 찾은 사례가 뒤에 나옵니다.
  3. 여러 단어를 띄어 쓰면 모든 단어가 들어간 사례만 보여줍니다. 예: 계약 보증. 모든 단어가 들어간 사례가 없으면 일부 단어만 들어간 사례를 따로 볼 수 있습니다.
  4. 조사가 붙어도(계약을), 초성만 입력해도(ㅈㅎㅅ → 지하수), 한/영 전환을 잊고 입력해도(rPdir → 계약) 찾아 줍니다. 오타가 있으면 비슷한 낱말을 제안합니다.
  5. 업무분야·기관·연도·감사유형·처분유형으로 결과를 좁힐 수 있습니다.
  6. 찾는 사례가 없으면 감사자료원 탭에서 해당 기관의 공식 감사결과 목록으로 이동해 직접 확인하세요.

검토상태 표시

검토대기 사례는 감사실 검토가 끝난 뒤 이 화면에 추가됩니다.

꼭 확인하세요

  • 이 화면은 업무 연찬용 참고자료입니다. 감사·처분 판단은 반드시 공식 원문, 관계 법령, 개별 사실관계를 확인해서 하세요.
  • 요약과 처분내용은 공개된 원문에 있는 내용만 옮겼습니다. 원문에 없는 법령은 ‘원문에서 확인’으로 표시합니다.
  • ‘공식 게시판 보기’로 표시된 사례는 게시판 목록으로 연결됩니다. 안내된 게시물을 목록에서 선택하세요.

보안 원칙

  • 파일 업로드, 첨부파일 자동 다운로드, 외부 AI 연결 기능이 없습니다.
  • 검색은 이 화면 안에서만 처리되며 입력한 검색어는 어디에도 저장·전송되지 않습니다.
  • 공개된 감사자료만 수록합니다. 개인정보, 진행 중 조사자료, 비공개 감사자료는 수록하지 않습니다.

공개 감사자료 기반 시범판 · 출처는 각 사례의 공식 게시물에서 확인하세요.
