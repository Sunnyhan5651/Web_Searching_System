업무 키워드 통합검색

어떤 업무를 확인하고 계신가요?

추천
결과 좁히기

이렇게 찾아보세요

  1. 담당 업무 용어를 입력합니다. 예: 계약, 보조금, 출장, 채용, 공유재산.
  2. 입력한 단어가 그대로 들어간 사례가 먼저 나오고 관련 사례가 뒤에 나옵니다.
  3. 여러 단어를 띄어 쓰면 모든 단어가 들어간 사례만 보여줍니다. 예: 계약 보증.
  4. 조사가 붙어도(계약을), 초성만 입력해도(ㅈㅎㅅ → 지하수), 한/영 전환을 잊어도(rPdir → 계약) 찾아 줍니다.
  5. 업무분야·기관·연도·감사유형·처분유형으로 결과를 좁힐 수 있습니다.

검토상태 표시

검토대기 사례는 감사실 검토가 끝난 뒤 추가됩니다.

꼭 확인하세요

  • 이 화면은 업무 연찬용 참고자료입니다. 감사·처분 판단은 반드시 공식 원문, 관계 법령, 개별 사실관계를 확인해서 하세요.
  • 요약과 처분내용은 공개된 원문에 있는 내용만 옮겼습니다.
  • '공식 게시판 보기'로 표시된 사례는 게시판 목록으로 연결됩니다.

보안 원칙

  • 파일 업로드, 첨부파일 자동 다운로드, 외부 AI 연결 기능이 없습니다.
  • 검색은 이 화면 안에서만 처리되며 입력한 검색어는 어디에도 저장·전송되지 않습니다.
  • 공개된 감사자료만 수록합니다.

공개 감사자료 기반 시범판 · 출처는 각 사례의 공식 게시물에서 확인하세요.
