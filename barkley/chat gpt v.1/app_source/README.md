# 감사사례 연찬 도우미 시범 앱 소스

공개 감사사례 57건과 전국 감사자료원 76개를 검색하는 정적 웹앱입니다.

## 정보보호 원칙

- 파일 업로드 기능이 없습니다.
- 첨부파일을 자동으로 다운로드하지 않습니다.
- 외부 생성형 AI API를 호출하지 않습니다.
- 공개 감사자료의 메타데이터와 공식 게시물 URL만 사용합니다.
- 개인정보, 조사자료, 비공개 감사자료를 저장하지 않습니다.

## 주요 폴더

- `dist/index.html`: 화면 구조
- `dist/style.css`: 화면 디자인
- `dist/app.js`: 감사사례, 검색·필터 기능
- `dist/data/sources.json`: 76개 감사자료원
- `dist/data/synonyms.json`: 업무분야별 검색 유의어
- `.gitlab-ci.yml`: GitLab Pages 배포 예시
- `.github/workflows/deploy-pages.yml`: GitHub Pages 배포 예시

## 확인방법

개발용 PC에서 `dist` 폴더를 정적 웹서버로 열어 확인합니다. `file://` 방식으로 직접 열면 브라우저의 보안정책 때문에 JSON 파일을 읽지 못할 수 있으므로 정적 웹서버 또는 Pages 환경을 사용해야 합니다.

## 공개 전 확인사항

1. `dist`에 엑셀, PDF, HWP, 개인정보 파일이 포함되지 않았는지 확인합니다.
2. 공식 게시물 URL이 정상인지 표본 점검합니다.
3. `계약`, `보조금`, `출장`, `채용`, `공유재산` 검색을 확인합니다.
4. 스마트정보과의 외부 서비스 및 공개저장소 사용기준을 확인합니다.
5. 승인된 저장소와 계정만 사용합니다.
